# LinkedIn Job Vacancy Scraper & Analysis 🚀

## 📌 Project Overview
This project is a professional data engineering and analysis pipeline designed to automate the sourcing of job vacancies. It scrapes real-time job data from LinkedIn, cleans the data, and provides actionable insights into the current job market.

## 🛠️ Tech Stack
- **Language:** Python
- **Web Scraping:** BeautifulSoup, Requests
- **Data Analysis:** Pandas
- **Data Visualization:** Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## 📊 Key Insights & Findings
After analyzing the scraped data, the following trends were identified:
- **Top Hiring Companies:** CAVA, Kiewit, and Waymo are leading the recruitment in this sector.
- **Geographic Trends:** The highest concentration of job openings is located in the United States, specifically in hubs like New York and Austin.
- **Market Demand:** There is a consistent demand for Data Analysts across various industries.

## 📂 Project Structure
- `linkedin_jobs_analysis.ipynb`: The complete Jupyter Notebook containing the scraping logic, data cleaning, and visualizations.
- `linkedin_jobs_analysis.csv`: The cleaned dataset extracted from LinkedIn.

## 🚀 How to Run
1. Clone this repository.
2. Install dependencies: `pip install requests beautifulsoup4 pandas matplotlib seaborn`.
3. Run the Jupyter Notebook.
